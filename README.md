# Dustworks

Start on foot with a vacuum. Recycle junk into parts, then build bins, belts and splitters, Vac Posts, Compactors and Smelters, programmable bots, a garage full of vehicles and Drone Hives until the whole rock cleans itself. iPad-first web game (add it to the Home Screen).

Play: https://noahwitchell.github.io/dustworks/
